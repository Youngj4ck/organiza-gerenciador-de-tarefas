2. Explicar brevemente a modelagem: USUARIOS, CATEGORIAS e TAREFAS; relações 1:N e chaves estrangeiras.
3. Mostrar que o back-end Python está conectado ao MySQL (endpoint `/api/health` deve informar `database: MySQL`).
4. Abrir a interface e mostrar os indicadores e a listagem.
5. Cadastrar uma tarefa, escolher responsável/categoria, alterar status, aplicar filtro e excluir uma tarefa de teste.
6. Mostrar rapidamente o MySQL Workbench com as tabelas e os relacionamentos.
7. Apresentar uma melhoria/correção feita após os cinco testes reais com colegas (somente depois que esses testes forem realizados).
